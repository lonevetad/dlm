Here follows a short additional explanation of the project:
As stated in that "structures_and_ideas.md" file, this project is aimed to design both a DAO ("Decentralized Autonomous Organization") (using the "Solidity" programming language as the target to implement all the "Smart Contracts") and a Back-End server to deliver a very engineering-heavy ambitious project: in short, running one or more LLM ("Large Language Model"), especially Open Source ones, across multiple independent small devices rather than relying on a single mainframe / data center; all of that to have some cryptocurrency in return, to allow users to use some LLMs' capabilities without needing a full ordinary subscription and to allow users to contribute in sustaining Open Source LLMs with the hardware tools at their disposal. To do so, each node in the network (whether a mobile phone, a laptop PC, a PC or a server) offer their hardware (RAM, CPU, bandwidth, local storage, etc) to store the LLM's shards (pieces), run the partial computation to properly digest an user prompt, concur if possible in the DAO's voting round, and run/store part of the blockchain underneath that DAO. This project took inspiration from "Edge Computing", the Bitcoin structure and specifically its algorithm to coordinate all "miners"' work, "Federated Learning", "Swarm Intelligence" and DAOs.
To ease the first development steps of this project, the mandatory constraint of having even the last computational steps (i.e., the ones that actually produce the resulting [textual?] output) is relaxed: a single node is allowed
