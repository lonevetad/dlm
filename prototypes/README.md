# Prototype and Version Archive

This directory stores major design iterations and prototypes for DLM.

## Structure

- v0-idea/ — initial concept and constraints, before design formalization.
- v1-dao-core/ — first DAO contract and governance concepts.
- v1-server-core/ — first backend server skeleton and orchestration logic.
- v2-model-scheduler/ — next-step prototype focused on shard scheduling and execution DAG.

## Rules

- Keep every major revision in this folder.
- Record the purpose, assumptions, and limitations of each prototype.
- Prefer incremental, documented experiments over large hidden rewrites.
